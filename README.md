# 🚗 Diar Car Buy AI

Python-агент для мониторинга и анализа объявлений о продаже автомобилей до
**140 000 ₽** в Москве и Московской области. Агент периодически парсит Avito
и Drom, прогоняет каждое объявление через Claude (по специализированному
промпту «перекупа»), считает потенциальную прибыль и DCB Score, а самые
интересные варианты присылает в Telegram. Дополнительно ведёт учёт ваших
сделок (покупка/продажа) и статистику.

## Описание проекта

- **Мониторинг** объявлений на Avito и Drom с фильтрами по цене и городу.
- **Анализ** через Claude API: оценка недооценённости, рисков, ликвидности,
  детектор перекупа, сезонность, расчёт прибыли и ROI.
- **DCB Score (0–100)** и вердикт по каждому авто.
- **Telegram-бот** с уведомлениями и набором команд управления.
- **Учёт сделок** с расчётом прибыли, срока владения и ROI.
- **SQLite** для хранения увиденных объявлений, истории цен и сделок.

## Требования

- **Python 3.10+**
- Telegram Bot Token и Chat ID
- Ключ Claude API (Anthropic)

## Установка

```bash
git clone <repo-url>
cd diar_car_buy
pip install -r requirements.txt
```

## Настройка `config.yaml`

Откройте `config.yaml` и заполните значения:

```yaml
TELEGRAM_BOT_TOKEN: ""        # токен бота от @BotFather
TELEGRAM_CHAT_ID: ""          # ID чата для уведомлений
CLAUDE_API_KEY: ""            # ключ Anthropic API
MAX_PRICE: 140000             # максимальная цена авто, ₽
MIN_DCB_SCORE: 70             # порог DCB Score для уведомления
CHECK_INTERVAL_MINUTES: 20    # интервал проверки, мин
CITIES: ["Москва", "Московская область"]  # фильтр городов
PAUSED: false                 # стартовое состояние мониторинга
```

Параметры `PAUSED`, `MAX_PRICE` и `MIN_DCB_SCORE` можно менять прямо во
время работы через команды бота — перезапуск не требуется.

## Запуск

```bash
python main.py
```

Логи пишутся в `agent.log`, данные — в `diar_car_buy.db`.

## Команды бота

| Команда | Описание |
|---|---|
| `/stats` | Статистика анализа за сегодня (проанализировано, отправлено, средний DCB Score) |
| `/top5` | Топ-5 объявлений за сегодня по DCB Score |
| `/pause` | Приостановить мониторинг |
| `/resume` | Возобновить мониторинг |
| `/budget [число]` | Изменить максимальную цену (бюджет) в runtime |
| `/score [число]` | Изменить порог DCB Score в runtime |
| `/bought [текст] за [число]` | Записать сделку (покупку авто) |
| `/sold за [число]` | Закрыть сделку (продажу), расчёт прибыли и ROI |
| `/deals` | Сводная статистика по всем сделкам |

Примеры:

```
/budget 120000
/score 75
/bought Lada Priora 2012 за 90000
/sold за 130000
```

## Как получить Telegram Bot Token

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям (имя и username бота).
3. BotFather пришлёт **токен** вида `123456789:ABCdef...` — впишите его в
   `TELEGRAM_BOT_TOKEN`.
4. Чтобы узнать **Chat ID**, напишите своему боту любое сообщение, затем
   откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе
   найдите `"chat":{"id":...}`. Это значение впишите в `TELEGRAM_CHAT_ID`.
