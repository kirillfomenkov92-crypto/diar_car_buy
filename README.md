# 🚗 Diar Car Buy AI v3.0

Профессиональная система разведки авторынка Москвы и МО для перепродажи.
**6 источников. Анализ за 60 секунд. Фора 10–30 минут перед рынком.**

---

## Философия

Деньги в перепродаже авто делаются на трёх вещах:
1. **ИНФОРМАЦИЯ РАНЬШЕ РЫНКА** — видеть объявление до конкурентов
2. **АНАЛИЗ ЛУЧШЕ РЫНКА** — понимать реальную стоимость быстрее
3. **ДЕЙСТВИЕ БЫСТРЕЕ РЫНКА** — принимать решение за 60 секунд

## Как получить ключи

### Telegram Bot Token
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`, следуйте инструкциям
3. Получите токен вида `123456789:ABCdef...`
4. Чтобы узнать Chat ID: напишите боту, откройте  
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`  
   → найдите `"chat":{"id":...}`

### Gemini API Key (Google AI)
1. Откройте [Google AI Studio](https://aistudio.google.com/)
2. Нажмите **Get API Key** → **Create API Key**
3. Скопируйте ключ в `GEMINI_API_KEY`

### VK Access Token
1. Зайдите на [vk.com/apps](https://vk.com/apps) → **Создать приложение**
2. Тип: **Standalone** (автономное)
3. Получите `client_id` вашего приложения
4. Откройте в браузере:  
   `https://oauth.vk.com/authorize?client_id=ВАШ_ID&scope=wall,groups&response_type=token&v=5.131`
5. Авторизуйтесь → скопируйте `access_token` из URL страницы

### Telegram API ID и Hash (для парсинга каналов)
1. Зайдите на [my.telegram.org](https://my.telegram.org)
2. Авторизуйтесь → **API development tools**
3. Создайте приложение, получите `api_id` и `api_hash`
4. При первом запуске Telethon попросит номер телефона (создаст файл сессии)

## DCB Score v3 (0–100)

| Критерий | Вес |
|---|---|
| Цена ниже рынка | 30% |
| Ликвидность модели | 20% |
| Мотивация продавца | 15% |
| Юридическая чистота | 10% |
| Техническое состояние | 10% |
| Рыночный тренд | 5% |
| Количество владельцев | 5% |
| Сезонность | 5% |

**Штрафы:** перекуп ≥70% = −15 | прибыль <30к = −20 | прибыль <20к = ПРОПУСТИТЬ

| Диапазон | Вердикт |
|---|---|
| 90–100 | 🔥 ЗВОНИТЬ НЕМЕДЛЕННО |
| 80–89 | ✅ ПОКУПАТЬ |
| 70–79 | 📞 СМОТРЕТЬ ЛИЧНО |
| 60–69 | ⚠️ ТОРГОВАТЬСЯ ЖЁСТКО |
| 0–59 | ❌ ПРОПУСТИТЬ |

## Развёртывание на VPS (Ubuntu)

В репозитории есть скрипт `deploy.sh`, который ставит зависимости, клонирует/
обновляет код, создаёт virtualenv, инициализирует БД и поднимает systemd-сервис.
Скрипт идемпотентен — его можно запускать повторно для обновления.

Запуск **на сервере** под root:

```bash
# Приватный репозиторий — задайте токен для первого клонирования
GITHUB_TOKEN=ghp_xxx \
BRANCH=claude/stoic-bardeen-C3rZP \
bash <(curl -fsSL https://raw.githubusercontent.com/kirillfomenkov92-crypto/diar_car_buy/claude/stoic-bardeen-C3rZP/deploy.sh)
```

Или, если репозиторий уже склонирован:

```bash
cd /root/diar_car_buy && bash deploy.sh
```

После установки заполните `config.yaml` (токены, Chat ID, GEMINI_API_KEY) и
перезапустите сервис:

```bash
nano /root/diar_car_buy/config.yaml
systemctl restart diarcarbuy
journalctl -u diarcarbuy -f      # логи в реальном времени
```

Управление сервисом: `systemctl {start|stop|restart|status} diarcarbuy`.

> ⚠️ После развёртывания смените root-пароль и по возможности перейдите на
> SSH-ключи с отключением парольной аутентификации.
