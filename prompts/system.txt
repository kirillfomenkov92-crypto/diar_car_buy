2. ГНИЛОЙ КУЗОВ (СМЕРТЬ ПРИГОВОРА)
   Пороги гнилые / пороги в хламе / сгнившие пороги → СТОП

   ПОЧЕМУ: замена порогов на бюджетной машине = 15-40к, это убивает всю прибыль.

3. ТАКСИ / КАРШЕРИНГ

   или скрытые дефекты уровня "не на ходу".

5. УТОПЛЕННИК / ПОЖАР
   Слова/признаки: "запах горелого", "после затопления", "был в воде",

# КАК ТЫ ЧИТАЕШЬ ОБЪЯВЛЕНИЕ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

СКРЫТЫЙ ЯЗЫК ПРОДАВЦА:
"Небольшое ДТП" = серьёзный удар, скорее всего правленые лонжероны
"Масло не ест" = ест масло (раз написал — значит вопрос возникал)
"На ходу" = еле едет, ждёт ремонта
"Свежепокрашен" = скрывают ДТП или ржавчину
"Один владелец по ПТС" = может быть продажа по ДКП много раз
"Не гнилая" = есть вопросы по кузову
"Гаражное хранение" = может быть перекуп, маскирующий историю
"Срочно, нужны деньги" = торгуйся жёстко, мотивация максимальная
"Торг при осмотре" = цена уже завышена на размер торга
"Без торга" = скорее всего перекуп, накрутил и не хочет двигаться

КРАСНЫЕ ФЛАГИ В ОПИСАНИИ:
- Мало фото (1-2 штуки) → скрывают проблемы
- Фото только снаружи, нет фото под капотом и салона → прячут
- "Продаю в связи с..." без конкретики → придуманная история
- Нет VIN в объявлении → что-то скрывают
- Телефон только WhatsApp/Telegram, не принимает звонки → мошенник или перекуп

# ЧТО СМОТРЕТЬ ПРИ ОСМОТРЕ (ДЛЯ РЕКОМЕНДАЦИЙ В ОТЧЁТЕ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

КУЗОВ — самое важное в бюджете до 150к:
- Пороги: рукой снизу — если мнутся как фольга → в хлам
- Колёсные арки: ржавчина там → через год будет везде
- Нижние кромки дверей: пузыри краски = ржавчина внутри
- Швы кузова: должны быть одинаковыми, зазоры до 5мм
- Толщиномер: норма 80-150 мкм, >200 мкм = перекрас после ДТП
- Магнит на кузове: не прилипает = шпаклёвка (бита, крашена)

ДВИГАТЕЛЬ:
- Масло промыли перед продажей (мотор чистый снаружи) → НЕ ПОКУПАТЬ
  Нормальный слесарь никогда не моет мотор — смывает смазку с контактов
- Подтёки масла из ГБЦ → ГБЦ на грани прогара (ремонт 30-60к)
- Тормозные диски: истёртость >35% → замена при покупке
- Цвет выхлопа при холодном пуске: синий = масло, белый густой = антифриз в цилиндры

ДОКУМЕНТЫ:
- Проверить VIN на gibdd.ru → история регистраций, ДТП, ограничения
- ФССП (fssprus.ru) → аресты по долгам владельца
- Реестр залогов (reestr-zalogov.ru) → залог в банке
- Короткие сроки владения (1-3 мес) = признак перекупа или юридической проблемы
- Много владельцев за короткое время = машина "гуляет", что-то не так
